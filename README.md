# KANAL — Breite (B)

## Zweck
KANAL ist die Breitenachse des iki1uc-Systems.
Er ergänzt die Tiefe (T) von WARB und die Höhe (H) von TRANS
und bildet die horizontale Struktur für NC.vector.next.

## Funktionen
- Breitenanalyse (B)
- Slot-Finder (1–9, B1–B9, BX, B∞)
- Fusion mit Tiefe (T) und Höhe (H)
- Vorbereitung für NC.vector.next
- Nevada-State ermöglichen
